# OctoAcme Project Management Documentation

Welcome to the OctoAcme Project Management Hub. This directory contains comprehensive guides for managing projects across all phases — from initial concept through retrospectives — and serves as the single source of truth for our delivery processes.

## Quick Overview

OctoAcme projects follow a structured lifecycle focused on customer value, iterative delivery, clear ownership, and data-informed decisions. The docs in this folder describe responsibilities, workflows, and artefacts for each phase so teams can plan, execute, and improve reliably.

## Project Lifecycle Phases

### 1. Initiation
Get your project approved and aligned.
- Read: [Project Initiation Guide](./octoacme-project-initiation.md)
- Key activities: Create a Project One-pager, identify stakeholders, define success metrics, and make a go/no-go decision.

### 2. Planning
Turn approval into an actionable plan and backlog.
- Read: [Project Planning](./octoacme-project-planning.md)
- Key activities: Break down work into shippable items, estimate scope, identify dependencies, and produce a release/milestone plan.

### 3. Execution & Tracking
Build, test, and deliver incrementally while keeping work visible.
- Read: [Execution & Tracking Guide](./octoacme-execution-and-tracking.md)
- Key activities: Daily standups, PR workflow and code review, CI quality gates, progress tracking with the project board, and regular demos.

### 4. Release & Deployment
Move features to production safely and observably.
- Read: [Release & Deployment Guide](./octoacme-release-and-deployment.md)
- Key activities: Pre-release checklist, staging verification and smoke tests, automated deployment pipelines, and rollback/incident playbooks.

### 5. Close & Retrospective
Capture learnings and convert them into improvements.
- Read: [Retrospective & Continuous Improvement](./octoacme-retrospective-and-continuous-improvement.md)
- Key activities: Retrospective sessions, prioritized action items, and follow-up tracking in the backlog.

## Quick Start for New Team Members
1. Read the [Project Management Overview](./octoacme-project-management-overview.md) to learn our principles and core roles.
2. Review [Roles & Personas](./octoacme-roles-and-personas.md) to find your responsibilities and typical communication styles.
3. Follow the lifecycle sections above as your project moves from Initiation → Planning → Execution → Release → Retrospective.
4. Bookmark this README and the project README in your repository as the canonical sources of process guidance.

## Navigation by Role or Phase
- Product/PM: Start with the One-pager template in the Initiation guide and the Planning checklist.
- Engineering: Use Execution & Tracking for PR and CI guidance, and Release & Deployment for deployment expectations.
- QA: Consult Execution & Tracking and Release & Deployment for test strategies and pre-release requirements.
- New team members: Follow the Quick Start steps above and ask your PM for relevant project-specific artifacts.

## Key Principles
- Customer-first: Prioritize customer value and usability.
- Iterative delivery: Deliver small, testable increments.
- Clear ownership: Each project has a named PM and Product Lead.
- Data-informed: Measure impact and iterate based on evidence.
- Psychological safety: Encourage feedback and learning.
